01 / WHY THIS GAME

23:17 之前，
艾达还站在吊灯下。

你在余映局放映一卷旧胶片。画面里，吊索已经断开，马丁还在撑着，米娅站在母亲身旁。艾达想活下来，也想和家人拍一张照片。

相机把你带进电影，停在事故发生前。搬动物件，排演一次，再拍下改变后的画面。救人有三种办法，但灯怎样被接住、马丁能否松手、照片里有谁，会继续改变回到街上后的事。

正式封存后，艾达活了下来，却失去这十二秒的记忆。她没交出去的原信还在。你要把它交到米娅手里，再沿着这次救援留下的证据，走到对岸影院。排演可以重来；一旦封存，她就不能再记起这一刻。

02 / ACTION → CONSEQUENCE

灯接住了。
马丁却未必能松手。

餐车留下撞痕，钩索让马丁空出手，撑杆留下锁位。到了 07 号，你要按这些证据读撞痕、对齐合影，或重搭支撑。

三条路都救下艾达，也都支付同样的记忆代价。区别会留在人物动作、照片和下一次操作里。

03 / ONE LETTER, DIFFERENT ROUTES

救下母亲，
把她的信交给女儿。

原信只有一封。可以经过 026 邮局和 027 邮车，也可以自己带回街上。车到站后，信还要从柜里取出来，亲手递给米娅。送递记录随后告诉你：07 号该用哪扇接收窗。

01 / 赶上邮车

让信随车离站。

在邮局装袋、盖戳。到 027 拍停行驶中的邮车，把邮袋装上架，再继续放映。

上层收件柜 → 取出原信 → 米娅亲收 → 固定窗

到站纸指向已经就位的固定窗，接下来把光对进去。

02 / 错过后补送

空车走了，信还在。

把同一只邮袋带回 026，放上补送盘。转动分拣轮对准 07，压下转送杆，让袋子通过出件口。

侧下方补送盘 → 取出原信 → 米娅亲收 → 滑动窗

补送纸指向侧面的滑窗。握住把手，把它拉回 07 白线，再对光。

03 / 亲手送到

自己把信交给她。

从 025 带回原信，直接递给米娅。她收到信后，07 号台侧会留下马丁的检修便条。

米娅亲收 → 马丁的便条 → 便携窗

按便条找到便携窗，拿起它，安装到黄铜座上。

救法决定检修哪一处，送法决定用哪扇窗。两条线在 07 号汇合：完成检修，接好光，退闩开盖，拍下完整图纸。之后才拍摄桥与楼梯，把照片展开成通往影院的路。

04 / DESIGN WITH AI

撑杆拿起来以后，
还得让人知道怎么用。

“这个伸缩杆怎么用？”是试玩里反复出现的问题。我让 Codex 把低位握轮、托头接触和锁止接成一段完整操作，并据此修改提示。故事、玩法和画面的取舍由我决定。

  1. 01 / THE BRACE

    撑杆要能从下面用。

    原来的“拿起、寻找细节”解释不了用途。我要求把低位握轮、托头接触和锁止做清楚，让提示跟着动作走。

  2. 02 / THE LETTER

    到站之后，还要交信。

    信在柜里时，米娅不能说自己收到了。我把到柜、取信、递交分成三个状态，让人物对白和物件位置一起变化。

  3. 03 / THE CONSEQUENCE

    三种救法接到下一关。

    餐车看撞痕，钩索对合影，撑杆重搭锁位。我把各自的前置条件、可操作部件和失败恢复写进连续关卡脚本，再交给 AI 实现。

  4. 04 / THE FRAME

    尺、纸和握柄看得清。

    判断范围、机位、遮挡、描边与局部灯光一起调整。每次修改都回到引擎画面，看玩家能否认出部件、读到线索。

AN EXAMPLE / 一条输出怎么改

从「拿起」
到「托住」。

原提示伸缩撑杆 · 拿起 · 寻找细节

改写示例放稳撑杆。转动低位握轮，让托头接触灯底；锁住后按 T 排演。

我要求提示写出对象、动作和完成条件，按键和文案与当前物件状态一致。

我看这四件事。

知道要做什么

手上真能操作

做法留下差别
照片、人物动作和下一段检修随选择改变。

05 / IMAGE & MATERIAL

珊瑚色大厅，
黄铜里的机关。

拱窗、长桌和吊灯把画面摆成一场家庭电影。奶油与珊瑚铺开空间，墨蓝压住结构，黄铜留给握轮、锁扣和灯架。近处的轮廓和局部光帮助辨认工具，青绿远景把对岸影院推到河的另一边。

奶油 / 纸珊瑚 / 建筑墨蓝 / 结构黄铜 / 机械青绿 / 远景

我从这些作品里带回了什么。

在《取景器》里，照片能变成脚下的路；《WILL》改变叙事顺序，也改变人物的命运。这两种做法让我开始考虑摄影和前后顺序怎样参与解谜。《星际拓荒》的工具资料用来整理线索关系。我正在玩《空之轨迹》，也把实机截图留作轮廓、材料和远近层次的参考。Pinterest 参考用于网格、色块和图文节奏。
