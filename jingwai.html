01 / WHY THIS GAME

我喜欢电影，
也想动手改一段电影。

“电影会摄取灵魂”的旧传闻，成了我的虚构起点。玩家是一位放映员，可以进入电影里停住的一刻，改变正在发生的事。放映之后，人物与物件会在现实街区留下变化。

首章从一家人的事故开始：艾达站在即将坠落的吊灯下，丈夫马丁和女儿米娅都在场。玩家要救她，再把她写给米娅的原信交到本人手里。救援并不是做完一个机关就结束，后面的检修要继续追问：这次改变靠什么成立？

虚构规则：正式封存一次，会让艾达失去这十二秒的亲身记忆。排演可以反复尝试；代价在最终提交时发生。她获救后的生活仍然继续。

02 / ACTION → CONSEQUENCE

救人的办法，
也会改变下一件事。

我希望玩家能从留下的照片和物件里，认出自己做过什么。救援方式因此继续决定 07 号需要完成的检修。

三种路线对应已实现的首章操作；图片保留各自的版本与来源。

03 / ONE LETTER, DIFFERENT ROUTES

同一封信，
送法改变下一次调查。

026 是整理原信与盖戳的邮局，027 是最后一班邮车。顺序的意义落在信实际去了哪里，而不是让玩家在菜单里选一个结局。

ON TIME / 正点邮车

让信跟车离站

把同一只邮袋盖好戳，拍停行驶中的邮车，亲手装袋，再继续放映。

上层收件柜 → 米娅亲收 → 固定接收窗

顺利到站的送递留下正式回执，07 号按固定窗口接光。

REDELIVERY / 错过后补送

把漏送的信找回来

空车先走，信不会消失。回 026 使用补送托盘、分拣轮和转送杆，把原袋送回 07 号。

侧方补送托盘 → 米娅亲收 → 滑动接收窗

漏送成为可以补救的过程，玩家要移动窗口，重新对上真实光路。

HAND DELIVERY / 亲手交付

自己把话带给米娅

从电影带回原信，直接交给米娅。信已经到本人手里，就不强迫玩家再跑一次邮路。

本人接收 → 马丁的便条 → 便携接收窗

面对面的交付留下个人便条；后续要拿起便携窗，放进黄铜座。

到站纸只证明同袋运送，不会自动打开后面的路。玩家必须交信、检修、调整光路、开盖并拍清图纸，检修完成以后，玩家直接拍摄桥与楼梯，把照片构筑成走得通的路。

04 / DESIGN WITH AI

先把判断说清，
再和 AI 一起做出来。

项目通过 Codex 的自然语言协作推进。我负责故事、玩法、审美与取舍，把玩家反馈写成制作要求；AI 协助生成脚本、功能资产、页面和检查流程，结果仍要回到实际游戏里看。

  1. 01 / DEFINE

    把感觉拆开

    “撑杆没用”要拆成：能否拿起、放在哪里、哪个握柄可操作、怎样接触灯底、成功后能看到什么。

  2. 02 / AUTHOR

    写清操作步骤

    记录前置条件、按键、对象身份、状态变化和失败恢复。把同一封原信、照片与回执分清，不靠模糊描述让 AI 自己补剧情。

  3. 03 / BUILD

    按用途做资产

    用 Blender 保留模型源文件，再接入 Unity。握柄、锁位、接收窗和碰撞须对应玩法；海报和纸面沿用同一套颜色、字体与印刷语言。

  4. 04 / REVIEW

    检查发生了什么

    核对实际按键、对象和引擎帧。代码能编译只是起点，玩家看懂提示、能走通、结果有区别，才是继续迭代的依据。

AN EXAMPLE / 一条输出怎么改

把“寻找细节”
改成玩家知道怎么做的话。

原提示的问题“伸缩撑杆 · 拿起 · 寻找细节”只告诉我能拿，没解释为什么拿、下一步去哪。

拆成可执行要求提示要写明当前对象、动作和下一步：放到吊灯下，操作低位握轮；托头接触灯底后锁住，再排演确认艾达安全。

这里呈现我的提示改写原则，不把展示稿冒充游戏逐字文案或训练数据。

我用四件事判断这次输出是否更好。

说清楚
人物、原件和目标不混淆，提示说明当前动作。
做得到
按键与真实物件对应，范围、遮挡和碰撞允许操作。
有后果
不同方法留下不同照片、器械与路线，不只改文案。
看得见
颜色、轮廓、灯光和纸面帮助判断，概念图不冒充实机。
05 / IMAGE & MATERIAL

画面要有电影的气质，
也要让机关看得懂。

奶油、珊瑚、墨蓝和黄铜统一空间；近处用轮廓、局部灯光和材料差异区分人物与工具，远处用青绿雾退到背景。纸本界面把收到的消息、原件和拍下的照片分开。

参考怎样进入我的作品

《取景器》让我关注摄影之后能走的空间，《WILL：美好世界》让我关注顺序的因果，《星际拓荒》和塞尔达的工具设计资料帮助我反思线索与操作。我在游玩《空之轨迹》时提供的实机图，则用于观察轮廓、材料与近远层次。本地保存的 Pinterest 参考采用“分类—选择—详情”的阅读节奏，本页的路线展示沿用这个原则；具体图像只在确认来源后采用。

我体验过《取景器》《WILL》和银河电灯的作品，也在玩《空之轨迹》。其他条目用于资料研究；我借鉴具体设计原则，再放回自己的故事和操作中。

WHAT EXISTS / WHAT COMES NEXT

先把一个首章做实，
再讨论更复杂的电影。

当前可玩首章

  • 电影进入、摄影取证与真实物件救援。
  • 三种救法与相应的后续检修。
  • 原信、邮袋、盖戳、摄影停帧装车与错过补送。
  • 米娅亲收、07号光路和完整检修图。
  • 检修后直接实拍桥梯，形成可走的通路。
  • Windows 包、Blender 源、关卡脚本与分版本记录。

后续设计方向

从单张照片扩展到录像，分离声音、动作和时间，再用自己获得的素材重新编排情节。电影中继续进入电影，最终让玩家怀疑“回到现实”是否真的完成。

这些方向会先写完整故事和连续脚本，再进入制作。当前首章尚未实现音轨剪接、电影层级栈、任意图片生成三维空间或正式跨重启存档。
